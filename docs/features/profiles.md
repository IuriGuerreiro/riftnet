# Profiles

Choose your account in the sidebar to open **Edit profile**. The panel lets you save a display name and bio, upload an avatar, or remove it.

## Check an update from another account

Use two accounts with an existing DM and a small image to upload.

1. Open a DM between two test accounts.
2. Change the first account's display name and choose **Save profile**.
3. Select an image for the avatar and choose **Save avatar**.
4. In the second session, confirm the DM shows the new display name and avatar. Reload that session and check both again.

The [profile architecture](../architecture/profiles.md) describes profile updates and avatar caching.
