# Attachments

Open a conversation and use **Attach files** beside the message field. An attachment becomes part of the message when you send it.

## Check an image from the recipient's history

Use two accounts with an existing DM and an API connected to local object storage.

1. Open a DM between two test accounts. Attach a small PNG and send the message.
2. In the recipient's session, confirm the message shows an image preview. Open or download the image and confirm it matches the original.
3. Reload the recipient's session and reopen the DM. Confirm the preview and download still work from message history.

Use a fresh upload for this check because attachments can expire.
