# Feature map

This map describes features in the current web client and API. Each page shows where to start, what to try, and what you should observe. The journeys describe expected behavior. Live status for the web journeys below is **pending**. The separate [auth API smoke](auth.md#api-smoke) passed against a fresh local stack.

| Feature | What to check |
| --- | --- |
| [Accounts and sessions](auth.md) | Register, choose a username, sign in, and log out. |
| [Messaging and group DMs](messaging.md) | Exchange messages, edit or delete a message, and create a group. |
| [Friends and presence](friends.md) | Accept a friend request and see a friend's status change. |
| [Profiles](profiles.md) | Save profile changes and see them from another account. |
| [Attachments](attachments.md) | Send an image and open it from the recipient's message history. |
| [Calls and screen sharing](calls.md) | Accept a call, hear audio both ways, and view a shared screen. |

For planned work, see the [project idea and MVP plan](../product/README.md).

For local setup, evidence, and cleanup, use the [verification skill](../../.agents/skills/verify-discord/SKILL.md).
