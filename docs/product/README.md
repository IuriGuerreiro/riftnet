# Project idea

Adept is an open source chat and calling app for gamers and coaches. It starts with friends, direct messages, and small groups. The project aims to make high quality screen sharing available in direct messages while keeping the client light.

- [Vision](vision.md) explains why someone would switch and records goals for screen sharing, memory use, file sharing, and self-hosting.
- [MVP plan](mvp.md) records the initial scope and build order. The first version focuses on direct messages and small groups. Community servers, extensions, and peer-to-peer transport are future work in the plan.

For the current app, see the [feature map](../features/README.md).
