# Vision

## What

An open source alternative to Discord, built in Rust.

## Why people switch

1. **Screen share at 60fps in source quality.** Free in DMs.
2. **Light app.** Under 1 GB of RAM.
3. **No file size limits.** P2P with a relay fallback.
4. **Yours.** Self-host a server, or run one from your own PC in one click.

## Goals

- Portfolio project with real product potential.
- Creating a server must be **free and one click**, like Discord. Self-hosting and premium are extras.

## Scale

|                 | Users    | Messages                          |
| --------------- | -------- | --------------------------------- |
| Realistic start | 20–500   | —                                 |
| Design target   | 100k MAU | ~2.5M/day, ~30/s avg, ~300/s peak |

Design for the target, build for the start. Don't over-optimise early.
