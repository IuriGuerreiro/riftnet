# Tiers and costs (estimates)

## Tiers

|           | DMs / groups | Free server         | Premium               | Self-host  |
| --------- | ------------ | ------------------- | --------------------- | ---------- |
| Transport | P2P          | SFU                 | SFU                   | Owner pays |
| Voice     | HQ           | 64 kbps             | HQ                    | Everything |
| Screen    | Source 60fps | 720p30, ~10 viewers | 1080p60 / source, 50+ | Everything |
| Files     | P2P          | 24h cache + P2P     | Permanent             | Everything |

Two ways to pay:

- **Personal subscription:** your stream goes out in high quality in **any** server.
- **Server boosts:** the community pays.

Group DMs are capped (5) so people don't use them to dodge paid server tiers.

## Costs at 100k MAU

| Scenario                       | Per month                            |
| ------------------------------ | ------------------------------------ |
| Hetzner/OVH + P2P              | ~€700–900                            |
| Everything through our servers | ~€1,300–1,500                        |
| AWS                            | ~$42k+ (never for media)             |
| MVP                            | ~€5–60 (one VPS / one dedicated box) |

- TURN: ~10–20% of P2P connections go through our relay.
- Revenue: 1–2% conversion × €4 = **€4–8k/month**.
